# Fotorama Hub

Hub de enlaces (estilo Linktree) para **Fotorama — Daniel H**, fotografía y video en Santiago de Chile.

## Contenido

- `index.html` — página principal del hub de enlaces.
- `support.js` / `image-slot.js` — runtime necesario para renderizar la página (no editar a mano).
- `logo-fotorama-full.png` — logo de Fotorama.
- `retrato-cliente.jpg` — retrato de Daniel Hernández.
- `BrittanySignature.ttf` — fuente personalizada usada en el diseño.
- `.thumbnail` — vista previa del diseño.

## Deploy

Sitio estático, desplegado en Vercel con deploy automático al hacer push a `master`.
